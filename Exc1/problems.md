# Проблемные места и их приоритизация

| Категория	                  | Проблема	                                 | Описание	                                                                                                                                                                                | Приоритет    |
|-----------------------------|-------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| Данные и производительность | 	Медленная обработка данных в DWH         | 	Текущее хранилище данных (DWH) на базе Microsoft SQL Server 2008 года не справляется с объемами данных (сотни терабайт), что приводит к задержкам в построении отчетов (часы ожидания). | 	Must have   |
| Интеграция                  | 	Сложность интеграции новых бизнесов	     | Добавление новых бизнесов (фармацевтические компании, производители медицинского оборудования) требует значительных усилий по интеграции и дописывания бизнес-логики в DWH.	             | Must have    |
| Архитектура                 | 	Устаревшие технологии                    | 	Использование устаревших технологий (Power Builder) затрудняет масштабирование и поддержку системы.	                                                                                    | Should have  |
| Безопасность                | 	Управление доступом к данным             | 	Отсутствие четкой системы управления доступом к данным может привести к утечкам конфиденциальной информации, особенно в медицинских и финансовых данных.                                | 	Must have   |
| Аналитика                   | 	Отсутствие гибкости в отчетах            | 	Текущая BI-система не позволяет бизнес-пользователям самостоятельно создавать отчеты, что замедляет процесс принятия решений.                                                           | 	Should have |
| Масштабируемость            | 	Ограниченная масштабируемость DWH        | 	Текущая архитектура DWH не позволяет легко масштабироваться при добавлении новых бизнесов или увеличении объемов данных.                                                                | 	Must have   |
| Производительность          | 	Низкая производительность ИИ-сервисов    | 	ИИ-сервисы на Python могут не справляться с растущими объемами медицинских данных, что замедляет обработку и анализ.                                                                    | 	Should have |
| Интеграция                  | 	Сложность взаимодействия между сервисами | 	Интеграционная шина на базе Apache Camel может не справляться с растущим количеством взаимодействий между сервисами, что приводит к задержкам.	                                         | Could have   |
| Управление данными          | 	Отсутствие единой витрины данных         | 	Бизнесу сложно получить единую картину по всем направлениям из-за отсутствия централизованной витрины данных.	                                                                          | Must have    |
| Технический долг            | 	Легаси-системы                           | 	Наличие устаревших систем (Power Builder, SQL Server 2008) увеличивает технический долг и затрудняет поддержку.                                                                         | 	Should have |
